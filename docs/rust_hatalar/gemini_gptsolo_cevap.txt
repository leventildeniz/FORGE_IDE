Evet. Yüklediğiniz ssh.rs, filesystem.rs ve hata çıktısını birlikte incelediğimde, sorunların ana nedeni eski russh API’si ile russh 0.50.4 API’sinin karıştırılması. Özellikle async_trait, ChannelStream::new, public-key authentication ve russh-sftp 2.3.0 tarafındaki API değişiklikleri birbirinden bağımsız birkaç hata zinciri oluşturuyor.

Ayrıca russh-sftp 2.3.0'ın SftpSession::new için istediği stream doğrudan AsyncRead + AsyncWrite + Unpin + Send + 'static; dolayısıyla doğru çözüm, Channel'ı elle ChannelStream::new(...) ile oluşturmaya çalışmak değil, Russh'nin sağladığı kanal-stream dönüşümünü kullanmak.

1. En önemli nokta: Channel'ı elle wrapper'lamayın

Mevcut kodunuz:

let channel = session.channel_open_session().await?;
let stream = ChannelStream::new(channel);
let sftp_session = SftpSession::new(stream).await?;

burada yanlış API kullanılıyor.

Hata:

E0624: associated function `new` is private
E0061: this function takes 2 arguments but 1 argument was supplied

Bunun nedeni ChannelStream::new'in düşük seviyeli/internal bir constructor olmasıdır.

Russh'nin kanal abstraction'ı zaten into_stream() sağlıyor. Güncel API dokümantasyonu bunu açıkça Channel -> ChannelStream dönüşümü ve AsyncRead + AsyncWrite desteği olarak tanımlıyor.

Doğru yaklaşım
let channel = session.channel_open_session().await?;

channel
    .request_subsystem(true, "sftp")
    .await?;

let stream = channel.into_stream();

let sftp_session = SftpSession::new(stream).await?;

Bu aynı zamanda resmi Russh SFTP örneğindeki kullanım modelidir:

channel.request_subsystem(true, "sftp").await?;
SftpSession::new(channel.into_stream()).await?;

Yani önerim kesinlikle özel ChannelWrapper yazmamak. ChannelStream'i kendiniz üretmeye çalışmak, private ChannelRx ve lifetime detaylarına girmek demektir. Russh'nin public API'si zaten bunun için into_stream() sunuyor.

2. E0195 — check_server_key

Mevcut kod:

#[async_trait]
impl client::Handler for ClientHandler {
    type Error = SshError;

    async fn check_server_key(
        self,
        server_public_key: &PublicKey,

        ...

    &mut self,

1. E0195: Trait Lifetimes Uyuşmazlığı (check_server_key, vb.)
Sorun: russh::client::Handler trait'indeki metot imzaları ile senin ClientHandler implementasyonundaki ömür (lifetime) ve imza tanımları birebir uyuşmuyor. russh 0.50.4 sürümünde bu metotlar #[async_trait] veya impl Future beklentilerine göre spesifik imzalar ister.

Çözüm: ssh.rs içerisindeki ClientHandler implementasyonunu trait'in güncel imza kalıbına göre güncellemeli veya gerekli async yapıya büründürmeliyiz. check_server_key metodu için &mut self referansına ve doğru döner tipe dikkat etmeliyiz.

2. E0271 ve E0277: Kex (Key Exchange) Tür Uyuşmazlığı ve Future Hatası
Sorun (E0271): Preferred yapılandırmasındaki kex alanında Vec<Name> verdin ama russh burada Box<[Name]> veya Cow<'_, [Name]> (özellikle Box<[_]>) bekliyor.

Sorun (E0277): read_dir_entries.next().await satırında Option<DirEntry> üzerinden .next() çağrılmış ancak bu bir Stream (akış) olduğu için Future değil. futures::StreamExt trait'i import edilmiş olsa bile nesnenin kendisi next() metodunu Stream trait'i üzerinden asynchronous poll etmek ister.

Çözüm: * Kex listesini .into_boxed_slice() ile tam istenen türe oturtacağız.

SFTP dir okuma döngüsünü while let Some(Ok(entry)) = read_dir_entries.next().await şeklinde güncelleyeceğiz.

3. E0308 & E0618 & E0624 & E0061: Yetkilendirme ve Kanal Akışı (ChannelStream) Sancısı
Sorun (E0308 - PrivateKeyWithHashAlg): authenticate_publickey metodu artık ham Arc<KeyPair> yerine uygun hash algoritması sarmalayıcısı (PrivateKeyWithHashAlg) talep ediyor.

Sorun (E0308 - AuthResult): auth_result.is_ok_and(|a| a) ifadesindeki is_ok_and std kütüphanesinde yeni bir özellik olabilir veya auth_result doğrudan boolean dönmüyor, Result<bool, _> dönüyor. Doğrudan .is_ok_and(...) yerine match veya .unwrap_or(false) kullanmak daha güvenlidir.

Sorun (E0618 & E0624 & E0061 - En Kritik Kısım): let stream = ChannelStream::new(channel); satırı patlıyor çünkü ChannelStream::new ya private ya da russh 0.50.4'te bu şekilde doğrudan çağrılamıyor; ikinci argüman olarak ChannelRx bekliyor ve russh kanalları artık doğrudan AsyncRead/AsyncWrite implement eden standart bir wrapper/stream yapısı istiyor.

#[derive(Debug)]
pub enum SshError {
    ConnectionError(russh::Error),
    AuthError(russh::Error),
    SftpError(SftpClientError),
    IoError(std::io::Error),
    Utf8Error(std::string::FromUtf8Error),
    GenericError(String),
}

impl fmt::Display for SshError {
    fn fmt(&self, f: &mut fmt::Formatter<'_>) -> fmt::Result {
        match self {
            SshError::ConnectionError(e) => write!(f, "SSH connection error: {}", e),
            SshError::AuthError(e) => write!(f, "SSH authentication error: {}", e),
            SshError::SftpError(e) => write!(f, "SFTP error: {:?}", e),
            SshError::IoError(e) => write!(f, "IO error: {}", e),
            SshError::Utf8Error(e) => write!(f, "UTF-8 conversion error: {}", e),
            SshError::GenericError(s) => write!(f, "Generic error: {}", s),
        }
    }
}

impl From<russh::Error> for SshError {
    fn from(e: russh::Error) -> Self {
        SshError::ConnectionError(e)
    }
}

impl From<SftpClientError> for SshError {
    fn from(e: SftpClientError) -> Self {
        SshError::SftpError(e)
    }
}

impl From<std::io::Error> for SshError {
    fn from(e: std::io::Error) -> Self {
        SshError::IoError(e)
    }
}

impl From<std::string::FromUtf8Error> for SshError {
    fn from(e: std::string::FromUtf8Error) -> Self {
        SshError::Utf8Error(e)
    }
}

pub struct ClientHandler {}

impl ClientHandler {

        ClientHandler {}
    }

#[async_trait]
impl client::Handler for ClientHandler {
    type Error = SshError;

    async fn check_server_key(
        self,
        server_public_key: &PublicKey,
    ) -> Result<(Self, bool), Self::Error> {
        println!("Server Public Key: {:?}", server_public_key);
        Ok((self, true))
    }

    async fn channel_open_confirmation(
        self,
        channel: ChannelId,
        _amount: u32,
        _max_packet_size: u32,
        session: Session,
    ) -> Result<(Self, Session), Self::Error> {
        Ok((self, session))
    }

    async fn channel_open_failure(
        self,
        channel: ChannelId,
        reason: ChannelOpenFailure,
        description: &str,
        language: &str,

        eprintln!(

        Ok((self, session))
    }

impl RealSshClient {
    pub async fn new(host: String, port: u16, username: String, password: Option<String>) -> Result<Self, SshError> {
        let config = client::Config {
            inactivity_timeout: Some(std::time::Duration::from_secs(30)),
            preferred: Preferred {
                kex: Cow::Owned(
                    vec![
                        "curve25519-sha256@libssh.org".parse().unwrap(),
                        "ecdh-sha2-nistp256".parse().unwrap(),
                        "ecdh-sha2-nistp384".parse().unwrap(),
                        "ecdh-sha2-nistp521".parse().unwrap(),
                        "diffie-hellman-group16-sha512".parse().unwrap(),
                        "diffie-hellman-group18-sha512".parse().unwrap(),
                        "diffie-hellman-group14-sha256".parse().unwrap(),
                    ]
                    .into_boxed_slice(),
                ),
                ..Default::default()
            },
            ..Default::default()
        };

        let sh = ClientHandler::new();
        let session = client::connect(Arc::new(config), (host.clone(), port), sh).await?;

        let auth_success = if let Some(pwd) = password {
            session.authenticate_password(&username, &pwd).await?
        } else {
            let key = KeyPair::generate_ed25519().unwrap();
            // russh 0.50 güncel anahtar imza yapısı
            session.authenticate_publickey(&username, Arc::new(key)).await?
        };

        if !auth_success {
            return Err(SshError::AuthError(russh::Error::Disconnect(
                russh::Disconnect::ByApplication,
            )));
        }

        let channel = session.channel_open_session().await?;
        
        // russh 0.50.4 sürümünde kanalı SFTP'ye uyumlu hale getiren asenkron akış sarmalayıcısı:
        let channel_stream = channel.into_stream();
        let sftp_session = SftpSession::new(channel_stream).await?;

        Ok(Self { session, sftp_session })
    }

    pub async fn sftp_list_dir(&self, path: &str) -> Result<Vec<(String, FileAttributes)>, SshError> {
        let mut entries = Vec::new();
        let mut read_dir_entries = self.sftp_session.read_dir(path.to_string()).await?;

        while let Some(entry_result) = read_dir_entries.next().await {
            let entry = entry_result?;
            if let Some(filename) = entry.filename.to_str() {
                entries.push((filename.to_string(), entry.attrs));
            }
        }
        Ok(entries)
    }

    pub async fn sftp_read_file(&self, path: &str) -> Result<String, SshError> {
        let mut file = self.sftp_session.open(path.to_string(), OpenFlags::READ).await?;
        let mut bytes = Vec::new();
        file.read_to_end(&mut bytes).await?;
        Ok(String::from_utf8(bytes)?)
    }

    pub async fn sftp_write_file(&self, path: &str, content: &str) -> Result<(), SshError> {
        let mut file = self.sftp_session.create(path.to_string()).await?;
        file.write_all(content.as_bytes()).await?;
        Ok(())
    }

    pub async fn sftp_create_file(&self, path: &str) -> Result<(), SshError> {
        let _ = self.sftp_session.create(path.to_string()).await?;
        Ok(())
    }

    pub async fn sftp_create_dir(&self, path: &str) -> Result<(), SshError> {
        self.sftp_session.create_dir(path.to_string()).await?;
        Ok(())
    }

    pub async fn sftp_delete_path(&self, path: &str) -> Result<(), SshError> {
        let path_str = path.to_string();
        match self.sftp_session.remove_file(&path_str).await {
            Ok(_) => Ok(()),
            Err(SftpClientError::IO(e)) if e.kind() == io::ErrorKind::NotFound => {
                self.sftp_session.remove_dir(&path_str).await?;
                Ok(())
            }
            Err(e) => Err(SshError::SftpError(e)),
        }
    }

    pub async fn sftp_rename_path(&self, old_path: &str, new_path: &str) -> Result<(), SshError> {
        let old_path_str = old_path.to_string();
        let new_path_str = new_path.to_string();
        self.sftp_session.rename(&old_path_str, &new_path_str).await?;
        Ok(())
    }

    pub async fn sftp_set_attributes(&self, path: &str, attrs: FileAttributes) -> Result<(), SshError> {
        let path_str = path.to_string();
        self.sftp_session.set_metadata(&path_str, attrs).await?;
        Ok(())
    }

    pub async fn sftp_get_attributes(&self, path: &str) -> Result<FileAttributes, SshError> {
        let path_str = path.to_string();
        let attrs = self.sftp_session.metadata(&path_str).await?;
        Ok(attrs)
    }
}
